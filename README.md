# Anmala | أنمله

### An Arduino-Based 3D-Printed Robotic Arm — V1

Anmala V1 is a 3D-printed robotic arm implementation based on an
original robotic arm design by Kelton.

The project focuses on the practical implementation of the robotic
arm, including hardware integration, 3D printing, assembly,
calibration, testing, and troubleshooting.

## Hardware

The project uses:

- Arduino Board
- Servo Driver Board
- Standard Servo Motors
- 20KG Servo Motor
- Micro Servo
- Potentiometers
- 3S LiPo Battery
- Buck Converter
- Power Switch
- Controller Push Button
- Wires and Connectors
- Mechanical screws and components

More details are available in:

[`01_Hardware/Components.md`](01_Hardware/Components.md)

## 3D Printing

The robotic arm components were manufactured using:

- Creality Ender-3 S1 Pro
- 0.4 mm nozzle
- PLA
- PETG

Klipper was also used as the printer firmware environment during
the project.

More details:

[`03_3D_Printing/Printing.md`](03_3D_Printing/Printing.md)
