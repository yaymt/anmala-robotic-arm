\# Hardware Components



This document lists the main hardware components used in the

Anmala V1 robotic arm implementation.



\## Electronics



| Component | Description |

|---|---|

| Arduino Board | Main microcontroller |

| Servo Driver Board | Controls multiple servo motors |

| Potentiometers | Manual joint position control |

| LED | Status indication |

| Power Switch | Main power control |

| Controller Push Button | User input/control |

| Wire and Connectors | Electrical connections |

| T-Plugs | Power connections |

| Wire / Heat Shrink Wrap | Wiring insulation and protection |



\## Actuators



| Component | Description |

|---|---|

| Standard Servo Motors | Robotic arm joint actuation |

| 20KG Servo Motor | High-torque joint actuation |

| Micro Servo | Small mechanism / gripper actuation |



\## Power System



| Component | Description |

|---|---|

| 3S LiPo Battery | Main power source |

| Buck Converter | Steps down the LiPo battery voltage to the required operating voltage |

| Power Switch | Main power control |

| T-Plugs | Battery and power connections |



\## Mechanical Components



| Component | Description |

|---|---|

| Gripper Gears | Gripper mechanism |

| Large Screw Set | Mechanical assembly |

| Small Screw Set | Mechanical assembly |

| Rubber Bands | Mechanical assembly/support |

| Clear Acrylic | Structural component |

| Gripper Foam Pad | Gripper contact surface |



\## 3D Printing



| Component | Description |

|---|---|

| 3D Printing Filament | Material used to manufacture the printed parts |



\## Testing and Assembly Tools



| Component | Description |

|---|---|

| Adjustable Power Supply | Used for setup, testing, and troubleshooting |
